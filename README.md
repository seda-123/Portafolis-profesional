# 🚀 Free Project: Ecosistema Digital Integrat

Benvingut al meu repositori personal on recullo el desenvolupament del **Projecte Intermodular**. Aquesta iniciativa uneix la gestió empresarial, el desenvolupament de programari, la infraestructura de sistemes i el màrqueting digital en una única solució.

---

## 👤 1. Anàlisi de Competències Personals

En aquest apartat reflexiono sobre el meu perfil professional, integrant coneixements tècnics i una autoavaluació d'habilitats.

### 🛠️ Competències Tècniques (Hard Skills)

| Àrea | Tecnologia | Descripció |
| :--- | :--- | :--- |
| **Programació** | Java (Swing) | Domini de POO i creació d'interfícies gràfiques interactives. |
| **Bases de Dades** | SQL | Disseny d'estructures, *procedures* i *triggers* per a lògica interna. |
| **Web Design** | HTML/CSS | Enfocament *Mobile First* i disseny d'identitat corporativa. |
| **Sistemes** | Ubuntu / Win Server | Configuració de servidors, gestió de xarxes i seguretat. |
| **DevOps** | Git/GitHub | Gestió professional del codi i col·laboració en entorns de dev. |

### 💡 Exemples Reals d'Ús
* **Java:** Programació de la lògica de moviment i detecció de col·lisions en un joc 2D.
* **SQL:** Creació d'un *trigger* al sistema *Football Manager* per al control pressupostari automàtic.
* **HTML/CSS:** Disseny de *Landing Page* amb *media queries* per a visualització mòbil òptima.
* **Servidors:** Configuració de domini a Windows Server 2019 amb estructura de permisos empresarial.

### 📈 Fortaleses i Millores
* **Punts forts:** Networking (xarxes), Creativitat (disseny i identitat) i Orientació Estratègica.
* **Pla d'Acció:** * 📅 **Organització:** Ús de taulers Kanban (GitHub Projects).
    * 🧠 **Pensament Analític:** Disseny previ amb diagrames de flux.
    * 🤝 **Empatia:** Implementació de tests d'usuari (UX).

## 📂 2. El Projecte: Free Project

**Rol:** Desenvolupador Full-stack i Administrador de Sistemes.

Una proposta digital completa que integra:
- **ERP/CRM:** Gestió amb Dolibarr.
- **Gaming:** Videojoc 2D en Java.
- **Web:** Landing Page de producte.
- **Sistemes:** Infraestructura de servidors segura.

---

## ⚙️ 3. Desenvolupament i Reptes

### 🏥 Gestió de Clínica Veterinària
Implementació de **Dolibarr** per organitzar:
- Fitxes de clients i mascotes.
- Control d'inventari de productes.
- Gestió de vendes i facturació automatitzada.

### 🎮 Videojoc 2D (Java Swing)
Desenvolupament integral d'un joc interactiu que inclou:
- Gestió de perifèrics (teclat/ratolí).
- Sistema de puntuacions persistent en BD.
- Control de versions estricte mitjançant **Git branches**.

### 🏗️ Infraestructura i Dades
- **SQL Avançat:** Automatització de tasques mitjançant *Procedures* i *Triggers* al projecte *Football Manager*.
- **Sistemes:** Configuració completa d'Ubuntu i Windows Server (usuaris, grups i monitoratge).
- **Anàlisi:** Disseny de diagrames de casos d'ús per definir les interaccions actor-sistema.

### 📢 Màrqueting i Presentació
- **Landing Page:** Web responsive amb accés directe al joc i al manual d'identitat.
- **Pitch:** Fitxa de producte en anglès i presentació professional per a inversors.

---

## 🎓 4. Conclusions

Aquest projecte m'ha permès consolidar coneixements transversals en un entorn pràctic. He après que el desenvolupament d'un producte d'èxit no només depèn del codi, sinó d'una **planificació estratègica**, una **documentació rigorosa** i una **infraestructura sòlida**.
